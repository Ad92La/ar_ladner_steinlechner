# Project for university ("Industrial Computing - AR)

## 1. Step in developement
- Find a proper model to create a model target of an Raspberry Pi 5.
- Create the Model target with the Vuforia Model Target Generator
- Add a simple scene with tracks a real raspberry pi 5 and adds labels for the parts on the platine as well as an overview for the gpio pins.

## 2. Step
- Build an assembling of the Raspberry Pi 5 into a case

## 3. Step
- Add an intro scene to navigate between the scenes and prepare for further extensions.
