# Project for university ("Industrial Computing - AR)

## 1. Step in developement
- Find a proper model to create a model target of an Raspberry Pi 5.
- Create the Model target with the Vuforia Model Target Generator based on an .stl file for a rasberry pi 5.
- Add a simple scene witch tracks a real raspberry pi 5 and adds labels for the parts on the platine as well as an overview for the gpio pins.

## 2. Step
- Build an assembling of the Raspberry Pi 5 into a case for a scene.
- Find matching object files on Onshape for a fitting case including a cooling rack and a ventilator.
- Create initial explosion view with a highlighted model target.
- Add animation for step by step assembling and reset of the model.
- Ensure the initial highlighted platine is seen (for example the usb ports and open ports in the case.

## 3. Step
- Add an intro scene to navigate between the scenes including a back button for the other scenes and prepare for further extensions.
